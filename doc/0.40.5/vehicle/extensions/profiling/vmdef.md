# `profiling_vmdef`

*File: `lua/vehicle/extensions/profiling/vmdef.lua` · VM: Vehicle · 363 lines · BeamNG.drive 0.40.5 (buildbot 302427 on GitLab)*

**Access:** extension `profiling_vmdef`: `extensions.load (vehicle VM)("profiling_vmdef")`, then the global `profiling_vmdef`

Third-party library: LuaJIT's jit.vmdef (Mike Pall), a generated file ("DO NOT EDIT") that contains the LuaJIT VM name tables: names of bytecodes, trace compiler IR instructions, built-in fast functions, trace errors, etc. It is used by LuaJIT tools (profiler, trace dump). No function: read-only data only.

## Notes

- The bytecode (bcnames) and IR (irnames) names are strings with fixed-width columns of 6 characters, not tables.
- File generated by LuaJIT: do not modify it; it must match the embedded LuaJIT version.

## Fields

| Field | Type | Description |
|---|---|---|
| `bcnames` | string | LuaJIT bytecode opcode names concatenated, 6 characters per name. |
| `ffnames` | table | Names of LuaJIT's built-in fast functions. |
| `ircall` | table | Names of the C functions called from the IR (CALL), 0-based. |
| `irfield` | table<integer, string> | Names of the internal object fields read by the IR (str.len, func.env, tab.meta, tab.array, cdata.ptr…), 0-based. |
| `irfpm` | table<integer, string> | Math functions of the IR operation FPMATH (floor, ceil, trunc, sqrt, exp, exp2, log, log2, log10, sin, cos, tan, other), 0-based. |
| `irnames` | string | Names of the trace compiler IR instructions concatenated, 6 characters per name. |
| `traceerr` | table | JIT compiler trace abort error messages, 0-based. |
