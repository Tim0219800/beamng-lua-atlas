# `editor_dynamicDecals_layerTypes_path`

*File: `lua/ge/extensions/editor/dynamicDecals/layerTypes/path.lua` · VM: Game Engine (GE) · 793 lines · BeamNG.drive 0.40.5 (buildbot 302427 on GitLab)*

**Access:** extension `editor_dynamicDecals_layerTypes_path`: `extensions.load("editor_dynamicDecals_layerTypes_path")`, then the global `editor_dynamicDecals_layerTypes_path`

"Path" layer type of the Dynamic Decals tool: decals placed along a path (control points interpolated linearly or as a Bezier curve), optionally oriented along the curvature, or replaced by the characters of a text with a font (atlas generated by the fonts module). Provides the "Path Properties" section (orientation, path type, font, text, interpolation steps; order 80), the inspector GUI of the path type, the action bar buttons "Finish path layer" and "Remove last path layer data point" (visible only while a path is being created) and the doc pages.

## Notes

- The action bar only shows its buttons if api.getEnablePathLayer() and api.hasActivePathLayer() are true; they call api.finishPathLayer() and api.removeLastPathLayerPoint().
- When a text is set, the interpolation steps field is disabled (characters replace the interpolated decals).
- In the inspector, the dataPoints and character positions are drawn in the world (debugDrawer:drawSphere and drawTextAdvanced with the index).
- The "Properties" page lists api.properties["Path Layer"]; its "Highlight" button opens the "Decal Properties" section and highlights the matching widget.
