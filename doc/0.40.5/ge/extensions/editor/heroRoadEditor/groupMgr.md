# `editor_heroRoadEditor_groupMgr`

*File: `lua/ge/extensions/editor/heroRoadEditor/groupMgr.lua` · VM: Game Engine (GE) · 1883 lines · BeamNG.drive 0.40.5 (buildbot 302427 on GitLab)*

**Access:** extension `editor_heroRoadEditor_groupMgr`: `extensions.load("editor_heroRoadEditor_groupMgr")`, then the global `editor_heroRoadEditor_groupMgr`

Central manager of the "groups" (roads) of the Hero Road Editor. A group is a Lua table describing a road: nodes/widths/normals, cross-section profile, materials, marking layers, placed elements (crosswalks, repairs, potholes, widenings, intersections, barriers), groundmodel paint and Edit/Live state. The module creates, copies, splits, joins, serializes and deletes groups, applies profile presets, holds the undo/redo functions and drives the rebuild: updateDirtyGroups resamples the centerline then calls mesh, sidewalkMgr, barrierMgr and layerMgr in the right order.

## Example

```lua
local gm = extensions.editor_heroRoadEditor_groupMgr
gm.addNewGroup('My road')
local g = gm.getGroups()[#gm.getGroups()]
gm.applyProfilePreset(g, 'country')
gm.addCrossing(g, 0.5) -- crosswalk in the middle
-- g.isDirty = true is set: updateDirtyGroups(false) rebuilds on the next frame
```

## Notes

- Each group is a SimGroup folder in MissionGroup named '<name> - <uuid>'; its canSave follows the road's state (false in Edit, true once baked/Live).
- Profile presets (applyProfilePreset): highway, city, country, ledge, rally, race, speedway, valley. Each sets lanes, lane width, crown, shoulder, superelevation, engineering radii, road class and markings.
- Default lane width 3.65 m (minimum 1.5 m); the roadway width = (lanesLeft + lanesRight) * laneWidthM, split into equal leftExtM/rightExtM. At least 1 lane in total (otherwise 1+1).
- Element defaults: crosswalk depthM 3.5 m; repair lengthM 8.0 m, coverage 0.6, density 0.08, sizes 2 to 4 m, random seed; pothole radius 2.0 m, depth 0.3 m, noise 0.15; widening 3.0 m wide, bay 30 m, tapers 40 m and 25 m; intersection flare 4.0 m, length 8.0 m, bevel 2.5 m; barrier 30 m, offset 0.5 m, side 'right', type 'guardrail'.
- The position t of placed elements is a normalized abscissa 0..1 along the centerline (plan length), adjusted by clampCrossingT to stay away from the ends (0.5 m clearance, or mid-road if too short).
- Rebuild order of an active road (not being dragged): sampleCenterline, rib points, then meshMgr.updateMesh, sidewalkMgr.updateGroup, barrierMgr.updateGroup, be:reloadCollision, recreateAutoGeneratedLayers, layerMgr.updateAllLayers (decals drape over the collision, hence the collision before them). During a drag (dragging) or with previewMesh == false, only buildRibbonEdges is called. A terrain road (isMesh == false) uses buildTerrainEdges and terrain painting.
- New group defaults: geometryMode 'engineered' (engRadiusM 40, engTransM 15, engVertLenM 40), latRes 16, lonRes 100, LOD 400/150/40 px, chunkLenM 120, material 'm_asphalt_new_01', US-style markings, automatic layers: light tracks, centerline, edge lines and lane lines active.
- deserializeGroup fills the default geometry 'spline' for old saves without geometryMode, while addNewGroup creates 'engineered'.
- serializeGroup empties the derived arrays (divPoints, etc.) of the actual group before encoding; serializeGroupToTable makes a copy and removes the runtime keys (decal ids, previewMesh, terraBaseline) for the session file.
- convertPathsToRoadGroups: the final message logs #paths - #groups as the number of ignored paths, which also counts already existing groups (potentially wrong message). It creates a group per path even if the path is too small (minimum size 10 m): these groups stay empty.
- addGroupToGroupArray does not call computeIdToIdxMap; addNewGroup, removeGroup, splitGroup and joinRoadSplines do.

### Parameter details

#### `editor_heroRoadEditor_groupMgr.addBarrier(group, t01)`

Adds a placeable barrier segment (guardrail, jersey or plastic) on one side, over a length window, at abscissa t01; the furniture is placed by barrierMgr after the rebuild.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created barrier (side, lengthM, offsetM, zOffsetM, type).

#### `editor_heroRoadEditor_groupMgr.addCrossing(group, t01)`

Adds a crosswalk at abscissa t01 ({ id, name, t, depthM 3.5, lateral 'carriageway' }) and marks dirty.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created crosswalk.

#### `editor_heroRoadEditor_groupMgr.addGroupToGroupArray(group)`

Adds an existing group to the array, with a unique name; creates its SimGroup folder if missing and sets its canSave (true if group.isEnabled == false).

- `group` (*table*) : Group to add.

#### `editor_heroRoadEditor_groupMgr.addJunction(group, t01)`

Adds an intersection (funnel flare on one side, this road being the trunk) at abscissa t01, with options giveWay, exitCenterline and breakEdge.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created intersection (flareM, lengthM, bevelM, side...).

#### `editor_heroRoadEditor_groupMgr.addNewGroup(name)`

Creates a new group with all default parameters (see notes), its transient scene folder and its automatic layers, adds it to the list and updates the id map. Returns nothing: the group is found with getGroups()[#getGroups()].

- `name` (*string|nil*) : Base name; default 'Hero Road N'. Made unique by util.generateUniqueName.

#### `editor_heroRoadEditor_groupMgr.addPothole(group, t01)`

Adds a procedural pothole (carved into the mesh) at abscissa t01; the adjustment extent is about the diameter.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created pothole (lateralM, lengthM, widthM, depthM, noise, cutMarkings, seed).

#### `editor_heroRoadEditor_groupMgr.addRepair(group, t01)`

Adds a repair patch cluster (scatter of asphalt decals, random seed) at abscissa t01 and marks dirty.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created cluster.

#### `editor_heroRoadEditor_groupMgr.addWidening(group, t01)`

Adds a flat widening on one side (layby, overtaking lane) at abscissa t01, with smoothed entry and exit tapers.

- `group` (*table*) : Hero Road group.
- `t01` (*number|nil*) : Normalized abscissa (default 0.5).
- **returns**: table|nil The created widening (side, widthM, bayLenM, taperInM, taperOutM, edgeBulge, laneDivider).

#### `editor_heroRoadEditor_groupMgr.applyProfilePreset(group, key)`

Applies a profile preset to the group (copies all its fields, resyncs the width, marks dirty). Does nothing if the key is unknown.

- `group` (*table*) : Hero Road group.
- `key` (*string*) : 'highway', 'city', 'country', 'ledge', 'rally', 'race', 'speedway' or 'valley'.

#### `editor_heroRoadEditor_groupMgr.barrierDefaults()`

Default values of a new barrier.

- **returns**: table { lengthM = 30.0, offsetM = 0.5, zOffsetM = 0.0, side = 'right', type = 'guardrail' }.

- `b` (*table*) : Gate.
- **returns**: number lengthM or 30.0 by default.
