# `gameplay_race_segment`

*File: `lua/ge/extensions/gameplay/race/segment.lua` · VM: Game Engine (GE) · 250 lines · BeamNG.drive 0.40.5 (buildbot 302427 on GitLab)*

**Access:** `require("extensions/gameplay/race/segment")` (file under extensions/ but not a regular extension)

Class of a race path segment: stretch between two pathnodes (from and to). Three representations are planned: "waypoint" (straight line between the two nodes), a navgraph path automatically filled with capsules, or manual capsules (points with radius). The segment tells whether a vehicle is inside it (contains) and whether it reached the end node (finished). The module returns a factory: require('/lua/ge/extensions/gameplay/race/segment')(path, name, forceId).

## Notes

- Inconsistent mode names: the local modes list is {'waypoint', 'navgraphCapsule', 'manualCapsules'}, but the code tests 'waypoint', 'navpath' and 'capsules'. The values 'navgraphCapsule' and 'manualCapsules' are handled nowhere: contains then returns false.
- A capsule is a point {pos, radius, name}; a segment's capsules link from, the capsulePoints, then to. The radius is linearly interpolated along each stretch.
- The capsules generated by fillNavpath carry _generated = true and are recomputed on each call of fillNavpath.
- isValid reads .missing on the from and to pathnodes: Lua error if either id does not exist in path.pathnodes.objects.
- contains in waypoint mode requires state.currentSegments, state.previousCorners and state.currentCorners.

## Class `C`

Race segment. Fields: path, id, name ("Segment <id>" by default), mode ('waypoint' by default), from and to (pathnode ids, -1 if none), capsulePoints, sortOrder, _drawMode.

The module returns a constructor: `local obj = require("gameplay_race_segment")(options)`.
