Flowgraph node 'Select Garage Sites' (once_instant category, author BeamNG). Picks a start spot in the mission's initial zones and an end spot in the destination zones (mission.initialZones and destinationZones, generated by mission:generateZoneLists if needed), from sitesData.parkingSpots. Avoids already used spots, enforces a distance between minDist and maxDist (otherwise takes the best candidate). Outputs: impulse 'loaded', startSpot, endSpot, startLocation, endLocation (zone names).

## Notes

- The best candidate is the one whose (distance - maxDist) is the smallest, which can be a negative value (too close).
- Spots are compared by name and marked as used in usedStartSpots / usedEndSpots.
