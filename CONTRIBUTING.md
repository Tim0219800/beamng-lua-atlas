# Contributing

Thanks for helping improve the atlas. *Version française plus bas.*

## Ways to help

- **Report a mistake** in a description, a type or a stub: open an issue with the "Documentation error" template,
  and give the module, the function and the game source line (`lua/...:line`).
- **Write descriptions** for a module that has none yet (no ✍ in the index): follow
  [`CONSIGNES_DESCRIPTIONS.md`](CONSIGNES_DESCRIPTIONS.md) (in French: one JSON file per Lua file in `descriptions/<version>/`).
  Everything must come from the game code: nothing invented, uncertain types stay `any`.
- **Report a game bug** you confirmed: open an issue with the "Game bug" template. This repository only documents bugs;
  report them to BeamNG too if they matter to you.

## Rules

- Never edit `doc/` or `stubs/` by hand: they are generated by `outils/generer.py`. Change `descriptions/` or the tools instead.
- Never commit files copied from the game folder.
- Descriptions are in French for now; English contributions are welcome in a separate `descriptions-en/` folder (to be wired into the generator).
- The CI checks that every description is valid JSON and that every stub parses.

## Regenerating

You need the game installed and the raw data (`donnees-<version>.zip` from the release, unzipped into `donnees/`):

```
python -I outils/generer.py 0.40.5
```

## Contribuer (français)

- **Signaler une erreur** : ouvrir une issue « Documentation error » avec le module, la fonction et la ligne source du jeu.
- **Rédiger des descriptions** : suivre [`CONSIGNES_DESCRIPTIONS.md`](CONSIGNES_DESCRIPTIONS.md), un JSON par fichier Lua dans `descriptions/<version>/`. Tout doit venir du code du jeu.
- Ne jamais modifier `doc/` ni `stubs/` à la main : ils sont générés. Modifier `descriptions/` ou les outils.
- Ne jamais committer de fichiers copiés du dossier du jeu.
